# جدول الحصص | Class Schedule App

تطبيق Flutter خفيف لجدول الحصص الأسبوعي — بدون إنترنت، والبيانات محفوظة على الجهاز.

## طريقة الحصول على APK بدون تثبيت أي شيء (الأسهل)

1. ارفع هذا المجلد بالكامل على مستودع GitHub جديد (public أو private).
2. GitHub سيبني الـ APK تلقائيًا بفضل ملف `.github/workflows/build-apk.yml`.
3. من تبويب **Actions** في المستودع، افتح آخر تشغيل (run) باسم "Build APK".
4. انتظر حتى يكتمل (علامة ✓ خضراء)، ثم انزل لأسفل الصفحة إلى قسم **Artifacts**.
5. حمّل `class-schedule-apk` — بداخله ملف `app-release.apk` جاهز للتثبيت.
6. انقل الملف لهاتفك الأندرويد وثبّته (فعّل "السماح بالتثبيت من مصادر غير معروفة" إذا طُلب منك).

## أو بناؤه محليًا (Local build)

يتطلب تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install):

```bash
flutter pub get
flutter build apk --release
```

الملف الناتج سيكون في:
`build/app/outputs/flutter-apk/app-release.apk`

## المميزات

- جدول أسبوعي (سبت → خميس) بنفس شكل الجدول الورقي التقليدي
- إضافة/حذف الحصص (اسم المادة، الوقت، القاعة، المدرس، اللون)
- حفظ البيانات محليًا على الجهاز (لا يحتاج إنترنت)
- دعم كامل للعربي والإنجليزي معًا (RTL/LTR)
- خفيف جدًا — بدون مكتبات خارجية ثقيلة
